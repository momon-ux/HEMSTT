# HEMSTT

HEMSTT ialah platform pengurusan HEM multi-sekolah.

- GitHub Pages untuk paparan pengguna.
- Google Apps Script untuk log masuk dan operasi pelayan.
- Google Sheets sebagai pangkalan data induk.
- Google Drive untuk logo dan fail sekolah.

Data HEM SmartTrack SK Ranggu tidak disentuh. HEMSTT menggunakan pangkalan data dan pelayan baharu.

## Struktur

- `docs/` — laman GitHub Pages.
- `apps-script/` — pelayan Google Apps Script.

Kod keselamatan pentadbir tidak disimpan dalam fail GitHub awam.
